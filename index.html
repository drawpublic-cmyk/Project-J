API 연동 (mock 모드)

아래 CONFIG 값만 채우면 됩니다 (index.html 하단 스크립트).

  • 카카오맵: KAKAO_JS_KEY에 JavaScript 키 입력 → 실제 지도 + 주변 화장실/편의점/프린터/지하철/버스 검색이 켜집니다. (developers.kakao.com에서 사이트 도메인 등록 필요)
  • 공공데이터포털: DATA_GO_KR_KEY(디코딩 서비스키) 입력. 브라우저 CORS 때문에 PROXY에 프록시 주소를 넣어야 합니다. 함께 드린 proxy.js를 node proxy.js로 실행 후 PROXY:"http://localhost:8787/".
  • 화장실: 카카오 키워드(화장실·공중·개방) + TOILET_DATA_URL에 전국공중화장실표준데이터 odcloud 주소를 넣으면 개방화장실까지 표시(좌표 없는 데이터라 주소를 자동 지오코딩). 버스: 도착정보(혼잡도) / 편의점·프린터: 카카오 검색(프린터는 무인·셀프 출력만).

자세한 셋업은 API_AND_REQUIREMENTS.md 참고.
